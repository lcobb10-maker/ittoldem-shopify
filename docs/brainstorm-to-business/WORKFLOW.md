# Brainstorm-to-Business Operating Workflow

## Gate 0 — Commercial thesis
Define customer, job-to-be-done, existing substitutes, distribution, price hypothesis, manufacturing cost, gross margin, repeat purchase, and strongest falsification test. Decision: **investigate / reject**.

## Gate 1 — Evidence inventory
Capture inventor's words without embellishment. Tag VERIFIED (documented), REPORTED (firsthand account), PROPOSED (not built), HYPOTHESIS (test needed), UNKNOWN. Track dates, owners, and evidence locations privately.

## Gate 2 — Landscape and IP
Search products, papers, patents and regulatory guidance. Compare *specific technical features*; avoid declaring novelty without review. Separate utility, design, trademark, copyright, and trade secret. Flag public disclosure risks; get counsel before releasing enabling details.

## Gate 3 — Experiment
State hypothesis, baseline/control, inputs, measurements, pass/fail thresholds, repeat count, materials, safety plan, and raw evidence location. Record failures, not only successes.

## Gate 4 — Business model
Model landed cost, channel fees, returns, CAC, repeat purchase, licensing vs direct sales, liability, and compliance. Run optimistic/base/pessimistic scenarios.

## Gate 5 — Decision
Proceed, redesign, license, pause, or stop. Record evidence, decision maker, rationale, and next checkpoint.

## Gate 6 — Founder history
Chronological first-person record: motivation, prototype, obstacles, collaborators, lessons, verified milestones. Never turn proposed work into claimed achievements.

## Suggested AI agent roles
CEO: commercial decisions; CTO: technical feasibility; research: sources; finance: assumptions; IP: counsel checklist; QA: challenge unsupported claims; historian: accurate narrative. No agent can certify patentability or invent evidence.

## 30/60/90 day example
30: evidence inventory + customer interviews + baseline measurements.
60: controlled prototypes + competitive mapping + preliminary economics.
90: counsel-reviewed IP plan + go/no-go + commercialization experiment.
