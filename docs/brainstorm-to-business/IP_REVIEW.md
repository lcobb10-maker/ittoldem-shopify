# IP and Publication Checklist

- [ ] Identify exact inventor(s) and ownership.
- [ ] List actual working embodiments separately from proposed variations.
- [ ] Record earliest known public disclosures and sales/offers.
- [ ] Compare specific features against prior patents and products.
- [ ] Review written description, enablement, drawings, and alternative embodiments with counsel.
- [ ] Separate utility patents, design patents (no design provisional), trademarks, copyright, and trade secrets.
- [ ] Confirm actual filing status, serial numbers, and deadlines privately.
- [ ] Review public repository for enabling disclosures, secrets, sensitive photos, CAD, and proprietary formulations.
- [ ] Never treat GitHub timestamps as patent priority.
- [ ] Use actual qualifying specimens for use-based trademark filings; mockups are not substitutes.
