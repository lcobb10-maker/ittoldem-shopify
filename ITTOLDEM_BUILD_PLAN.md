# ITT TOLD'EM Shopify Build

Development workspace for rebuilding the ITT TOLD'EM storefront on a modern Shopify theme foundation.

## Direction
- Keep the current live Ritual storefront untouched while development happens.
- Use Shopify's modern Horizon architecture as the reference/foundation.
- Build an editorial luxury-fashion storefront rather than a generic Shopify catalog.
- Prioritize mobile shopping, strong product imagery, drop storytelling, collection navigation, performance, accessibility, and conversion.
- Keep GVO, WE HAIR, FLAGLINE and experimental/custom products organized as distinct brand/product stories without diluting ITT TOLD'EM.

## Safety
No live-store publishing, pricing, inventory, payment, shipping, domain, customer, or order changes are performed from this repository without explicit approval.

## Initial build sequence
1. Establish clean theme source.
2. Create ITT TOLD'EM design tokens and typography hierarchy.
3. Build editorial header/navigation and announcement system.
4. Build homepage hero/drop system.
5. Build asymmetric collection/product grids.
6. Build richer product pages for custom and limited products.
7. Add mobile-first interactions and performance improvements.
8. Validate Shopify theme structure before connecting/deploying to a draft theme.
